## CLI Exam Generator  
Implementation by **NoJS** | Maintenance by **UTTeam**

---

## 📝 Project Overview

This project is a **command-line application** that allows users to manage a question bank in order to:

- 📖 Create an exam  
- 🧠 Take the exam  
- 📊 Review and consult results  

All interactions are performed directly in the **terminal (CLI environment)**.

The project is currently in **Phase 2 – Implementation**.

---

## ⚙️ Technologies Used

- Node.js
- prompt-sync
- readline-sync
- vcards-js
- gift-parser-ide
